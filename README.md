## Carrito Seguidor de Línea

# Universidad Veracruzana  
# Ingeniería en Instrumentación Electrónica

# Robot autónomo desarrollado para la experiencia educativa de Robótica


## Especificaciones Generales
| Característica | Valor |
|---------------|--------|
| Peso total | 543 g |
| Microcontrolador | ESP32 DevKit V1 |
| Sensores de línea | QTR-8A |
| Motores | 2 motores N20 |
| Driver de motores | L298N |
| Alimentación | 4 baterías recargables, 2 powerbanks |
| Cámara | ESP32-CAM |
| Sistema de arranque | Sensor LDR |
| Tipo de control | PID |


## Dimensiones
- Largo: 22 cm
- Ancho: 15 cm

## Características

- Seguimiento autónomo de línea.
- Arranque automático mediante detección de luz.
- Grabación FPV con ESP32-CAM.
- Chasis fabricado en acrílico cortado por láser.
- Control diferencial basado en sensores infrarrojos.
